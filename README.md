## 📌 Описание проекта

Программа предназначена для построения **минимального остовного дерева (MST)** во взвешенном неориентированном связном графе с использованием **алгоритма Прима**.

Результат работы программы сохраняется в формате **Graphviz (DOT)**, что позволяет визуализировать исходный граф и построенное остовное дерево.

### Ключевые особенности:
* Использование очереди с приоритетом (`std::priority_queue`) на базе двоичной кучи для выбора ребер минимального веса.
* Временная сложность алгоритма: $\mathcal{O}((V + E) \log V)$.
* Пространственная сложность: $\mathcal{O}(V + E)$.
* Экспорт результата в формате DOT для последующей визуализации через Graphviz.

## 🛠️ Сборка и запуск

### Требования
* Компилятор C++ с поддержкой стандарта C++11 или выше (`g++`, `clang++`, `MSVC`).
* Утилита **Graphviz** (необязательно, нужна только для генерации графических изображений `.png`).

### Сборка через `g++`

```bash
g++ -std=c++11 -Iinc src/main.cpp src/graph.cpp src/prim.cpp -o prim
```

### Запуск программы

Программа принимает два аргумента командной строки: путь к входному файлу с матрицей смежности и путь для сохранения результатов в формате `.dot`.

```bash
./prim input.txt output.dot
```

## 📥 Формат входных и выходных данных

### Входной файл (`input.txt`)
Файл представляет собой **матрицу смежности весов**:
* Первая строка: количество вершин $N$.
* Следующие $N$ строк: $N$ чисел, разделенных пробелами.
* `0` — отсутствие ребра; любое другое неотрицательное число — вес ребра.

**Пример:**
```text
6
0 4 2 0 0 0
4 0 1 5 0 0
2 1 0 8 10 0
0 5 8 0 2 6
0 0 10 2 0 3
0 0 0 6 3 0
```

---

### Выходной файл (`output.dot`)
Результат генерируется в формате **DOT**:

```dot
graph MST {
    label = "Minimum spanning tree (Prim's algorithm), total weight = 13";
    node [shape = circle];
    0; 1; 2; 3; 4; 5;
    0 -- 2 [label = "2"];
    2 -- 1 [label = "1"];
    1 -- 3 [label = "5"];
    3 -- 4 [label = "2"];
    4 -- 5 [label = "3"];
}
```

## 🖼️ Визуализация графа

Если у вас установлен **Graphviz**, вы можете сгенерировать PNG-изображение из полученного `.dot` файла:

```bash
dot -Tpng output.dot -o graph.png
```
