◆ run()

void Prim::run ( const Graph & graph)

Выполняет алгоритм Прима на заданном графе.

Алгоритм строит минимальное остовное дерево, начиная с вершины 0. Для хранения рёбер, пересекающих разрез, используется очередь с приоритетом (двоичная куча из STL).
