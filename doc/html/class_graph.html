Detailed Description

Взвешенный неориентированный граф, представленный списками смежности.

Граф загружается из текстового файла, содержащего матрицу смежности весов.

◆ loadFromMatrixFile()

bool Graph::loadFromMatrixFile ( const std::string & filename)

Загружает граф из файла с матрицей смежности весов.

Формат файла: первая строка содержит количество вершин N, далее N строк по N чисел — матрица весов. Нулевое значение означает отсутствие ребра, положительные значения — вес ребра. Граф предполагается неориентированным, поэтому матрица должна быть симметричной (учитывается только верхний треугольник).

Parameters
filenameИмя входного файла.
Returns
true, если граф успешно загружен.
